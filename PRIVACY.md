# Privacy

Subscription Skills is a set of text-only Claude skills. It contains no code that runs on your machine, no MCP servers, no hooks and no network calls.

- It does not collect, store or transmit any personal data.
- It sends nothing to the author or to any third party.
- Whatever you share with Claude while using these skills is handled by Claude under Anthropic's own privacy policy: https://www.anthropic.com/legal/privacy

Questions: open an issue at https://github.com/theoutlines/subscription-skills/issues
