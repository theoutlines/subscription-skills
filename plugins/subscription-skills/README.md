# Subscription Skills

10 skills for subscription-app monetization:

- **Benchmarks:** RevenueCat SOSA 2026, Adapty State of In-App Subscriptions 2026, FunnelFox Web2App 2026, AppsFlyer App Monetization 2026
- **Pricing:** the Adapty Pricing Index (64 countries)
- **Acquisition:** Adapty Apple Ads 2026
- **Routing:** a benchmark router that keeps metric definitions apart
- **Compliance:** a paywall review against App Store and Google Play subscription rules
- **Paywall teardown and A/B tests:** Adapty's paywall teardown and A/B test assistant (MIT, © Adapty Tech Inc.)

Start with `subscription-benchmarks` for any "is our number good / what should we test" question. Share a paywall screenshot for `paywall-teardown` (score and test ideas) and `paywall-store-compliance` (store rules). Ask `paywall-ab-test-assistant` whether a test idea is worth running.

The skills also work outside Claude, in any agent that supports [Agent Skills](https://agentskills.io): `npx skills add theoutlines/subscription-skills`.

## Install

Claude Code:

```
/plugin install subscription-skills --marketplace theoutlines/subscription-skills
```

In the Claude apps, add it from the plugin directory.
